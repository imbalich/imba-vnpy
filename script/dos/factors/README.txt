因子1：买卖不平衡因子 (Imbalance)
================================================================================

文件：factor1.dos

计算公式：
    imbalance = (bid_volume_1 - ask_volume_1) / (bid_volume_1 + ask_volume_1)

输入参数：
    - bid_volume_1: 买一挂单量
    - ask_volume_1: 卖一挂单量

输出范围：-1 ~ 1
    - +1: 完全买方主导（只有买单）
    -  0: 买卖平衡
    - -1: 完全卖方主导（只有卖单）

特性：
    - 无状态因子，每条数据独立计算
    - 实时反映当前订单簿的瞬时力量对比
    - 灵敏度高，但噪音较大

使用方法：
    run "i:/Imba/imba-vnpy/script/dos/factors/factor1.dos"
    select * from factor_imbalance_result


================================================================================
因子2：买方流动性压力因子 (Buy Liquidity Pressure)
================================================================================

文件：factor2.dos

计算公式：
    1. bid_vol_ma = mavg(bid_volume_1, 300)      // 买一量5分钟均值
    2. ask_vol_ma = mavg(ask_volume_1, 300)      // 卖一量5分钟均值
    3. buy_prop = bid_vol_ma / (bid_vol_ma + ask_vol_ma)  // 买方占比
    4. spd_ma = mavg(ask_price_1 - bid_price_1, 300)      // 平均价差
    5. 因子值 = buy_prop / spd_ma               // 单位流动性成本下的买方压力

输入参数：
    - bid_volume_1: 买一挂单量
    - ask_volume_1: 卖一挂单量
    - ask_price_1:  卖一价
    - bid_price_1:  买一价

输出范围：0 ~ ∞
    - 值越高：买方力量强 + 流动性好
    - 值越低：买方力量弱 或 流动性差

特性：
    - 有状态因子，需要 @state 装饰器
    - 使用 5 分钟滚动窗口（300条数据）
    - 反映趋势性的买方压力，更加平滑稳定
    - 需要积累约 300 条数据后才有有效输出

使用方法：
    run "i:/Imba/imba-vnpy/script/dos/factors/factor2.dos"
    select * from factor_flow_result

二、背离策略（趋势转折信号）
----------------------------

顶背离（可能见顶）：
    条件：因子1 持续上升 且 因子2 开始下降
    含义：瞬时买压强但趋势转弱
    操作：考虑减仓或止盈

底背离（可能见底）：
    条件：因子1 持续下降 且 因子2 开始上升
    含义：瞬时卖压强但趋势转强
    操作：考虑建仓或加仓


三、综合评分策略
----------------

将两个因子标准化后加权组合：

    // 标准化到 0-1
    imb_norm = (imbalance + 1) / 2      // -1~1 → 0~1
    blp_norm = min(buyLiqPressure / 阈值, 1)  // 截断到 0~1
    
    // 加权组合（趋势因子权重更高，因为更稳定）
    combined_score = 0.4 * imb_norm + 0.6 * blp_norm

评分解读：
    - 0.8 ~ 1.0: 强烈看涨
    - 0.6 ~ 0.8: 看涨
    - 0.4 ~ 0.6: 中性
    - 0.2 ~ 0.4: 看跌
    - 0.0 ~ 0.2: 强烈看跌

================================================================================
注意事项
================================================================================

1. 因子2 需要预热期（约 300 条数据），在预热期内输出值可能不准确

2. 因子阈值需要根据具体品种和市场特性调整

3. 建议结合其他技术指标（如价格趋势、成交量）综合判断

4. 高频因子对数据质量要求高，确保数据源稳定可靠

5. 回测验证后再用于实盘交易
